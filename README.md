## ???? Project Overview (English)
This diploma project covers the development, simulation, and construction of a modular 3-meter VTOL UAV (26.5 kg) for alpine search and rescue (SAR) operations, backed by the Austrian Armed Forces.

### Propulsion Concept:
To achieve maximum aerodynamic efficiency during cruise flight, the system eliminates dedicated hover motors (no quadcopter setup). Instead, the drone utilizes a **Dual-Tilt-Rotor system** (2 tilting main motors). The engines provide vertical thrust for takeoff and pivot 90� forward for highly efficient wing-borne forward flight.
